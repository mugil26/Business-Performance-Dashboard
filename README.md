# Business Performance Dashboard

## Project Overview

This dashboard provides a six-year analysis of business performance from **2014 to 2019**, focusing on revenue trends, profitability, and regional revenue distribution. It presents key business metrics through a clear and visually engaging dashboard.

## Key Features

- Six-year revenue performance analysis
- Total revenue and gross profit tracking
- Gross margin and revenue variance analysis
- Industry variance comparison
- Year-wise performance navigation
- Regional revenue analysis
- Gauge charts for regional performance

## Key KPIs

- **Revenue:** £20M
- **Gross Profit:** £7M
- **Gross Margin:** 34.56%
- **Industry Variance:** 15.89%
- **Revenue Target Variance:** -2.57%

## Regional Performance

The dashboard visualizes revenue across:

- England
- Scotland
- Northern Ireland
- Wales

Gauge charts provide a quick comparison of regional revenue performance.

## Dashboard Purpose

The dashboard helps users monitor financial performance, identify trends, compare regional contributions, and support data-driven business decisions.

## Use Cases

- Business Intelligence
- Financial Analysis
- Management Reporting
- Data Visualization
- Performance Monitoring
- Portfolio Projects
